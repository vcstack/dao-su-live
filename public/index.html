Đạo Sư LIVE

Hiệu ứng trên sóng TikTok — không phát thưởng thật trong game nào.

Quan trọng: Công cụ này không tự bắt đầu phiên live. Bạn phải lên live bằng app TikTok hoặc LIVE Studio trước, rồi mới bấm NỐI. Trang /song chỉ hiện hiệu ứng — thêm nó vào LIVE Studio / OBS như nguồn trình duyệt.

5. Thêm /song vào LIVE Studio hoặc OBS

  1. Mở http://localhost:3000/song (nút phía trên).
  2. TikTok LIVE Studio: Nguồn → Thêm → Trình duyệt / Browser → URL trên, kích thước 1080×1920.
  3. OBS: Nguồn → Browser → URL như trên, Width 1080, Height 1920. Bật “Shutdown source when not visible” tắt nếu muốn giữ game chạy.
  4. Nếu Windows hỏi tường lửa: bấm Cho phép (mạng riêng).
  5. Ảnh tự thay trong thư mục public/hinh/ (zuzai.png, daosu.png).
